# 3D-Modelle

Alle Modelle, auf die Schaltplan und Board verweisen, liegen hier. Die
Pfade im Projekt zeigen über `${KIPRJMOD}/packages3D/...` hierher, die
3D-Ansicht ist nach dem Klonen also sofort vollständig — unabhängig davon,
welche Bibliotheken auf dem jeweiligen Rechner installiert sind.

**Herkunft**

- Die `.step`-Dateien stammen bis auf eine aus der KiCad-Standardbibliothek
  (Resistor_THT, Capacitor_THT, Package_DIP, Package_TO_SOT_THT, Diode_THT,
  Buzzer_Beeper, Connector_*, Potentiometer_THT, Button_Switch_THT) und
  stehen unter deren Lizenz (CC-BY-SA 4.0 mit Ausnahme für erzeugte Werke).
- `GMSB0522102Y7EU--3DModel-STEP-533217.step` ist das Herstellermodell der
  2-mm-Bananenbuchse.
- `LCD_20x4_HD44780_12mm.wrl`, `USB_Mini-B_THT_Horizontal_MAD.wrl` und
  `Banana_2mm_Pair_MAD.wrl` sind für dieses Projekt selbst gebaut; das
  LCD-Modell bildet das Modul samt Buchsenleiste auf 12 mm Höhe ab.
